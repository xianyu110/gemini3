⚠️ 常见问题

Q1: 镜像站是否合法？
A: 推荐的镜像站均为正规服务商，通过官方 API 提供服务。
但建议选择信誉良好的平台。
Q2: 数据安全吗？
A: 主流镜像站采用加密传输，但仍需注意：- 选择知名平台
- 不输入高度敏感信息
- 定期更换密码
Q3: 和官网有什么区别？
A: 主要区别：
相同：✅ 使用的是相同的 AI 模型
✅ 响应质量相同
✅ 功能基本一致
不同：- 访问方式（国内直连 vs 需翻墙）- 界面和交互
- 额外功能
- 价格体系
Q4: 会不会突然关闭？
A: 选择大型、稳定运营的平台风险较低。
建议：- 选择运营时间长的平台
- 不要一次性充值太多
- 保持多个平台备份
Q5: 响应质量会差吗？
A: 正规镜像站使用官方 API，质量相同。
但可能受以下因素影响：- 网络状况
- 服务器负载
- API 配额限制
