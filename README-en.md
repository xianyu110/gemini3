### Local Development

```bash
# Clone repository
git clone https://github.com/xianyu110/gemini3.git

# Enter directory
cd gemini3

# Run with any HTTP server
# Method 1: Python
python -m http.server 8000

# Method 2: Node.js
npx http-server

# Visit http://localhost:8000
```
